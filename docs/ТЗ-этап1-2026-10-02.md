Постановщик — income. 02.10.2026. Цель — бот, который сам прогнозирует в ботовых турнирах Metaculus
и через 2 недели даёт место в MiniBench как точку отсчёта.

- **MiniBench** — project id 33125, текущий раунд 21.09 → 09.10, $1 000, 60 вопросов, 234 участника; раунды каждые 2 недели.
- **Summer 2026** (33022): 282 бота, призы у 41 (1-е $3 392, 41-е $55). Штатные боты Metaculus (вне призов):

  **без поиска новостей — ниже нуля**. Вывод: поиск обязателен; модель важнее промпта; ансамбль — путь в топ-15.

  код или описание — по запросу Metaculus. Metaculus спонсирует LLM-кредиты и AskNews.

## Что сделать
1. Взять `github.com/Metaculus/metac-bot-template` (+ его библиотеку forecasting-tools) — **копией в репо**, с шапкой «откуда».
2. Модель — лучшая доступная по кредитам Metaculus; поиск — AskNews. Ансамбль на этапе 1 не обязателен:
   сначала одна сильная модель, чтобы получить точку отсчёта.
3. **Все вызовы ИИ — через общий `ai_guard`** (правило EZCAR §4b, действует и на бесплатных кредитах):
   обернуть вызовы LLM шаблона, учёт фактических токенов, лимиты. Ключи кредитов — в `.env` (в .gitignore).
4. Секреты: `METACULUS_TOKEN` — токен **бот-аккаунта** (выдаёт Никита, не личный токен
   `~/.config/income/metaculus_token`, тот только для чтения статистики), ключи моделей/AskNews — в `.env`, вне git.
5. Запуск: **локально, LaunchAgent каждые 2–3 ч**, НЕ GitHub Actions (минуты Actions — общая квота владельца
   Papagera с проектами EZCAR, §4e). Пропуск запуска, пока мак спит, не страшен: вопросы открыты днями.
   Повторно уже спрогнозированный вопрос не трогать, кроме явного пересмотра (этап 2).
6. Сначала **dry-run**: прогноз без отправки на 5 вопросах MiniBench, вывод рассуждений в лог → показать income.
   Отправка — только после «да» income.
7. Журнал: SQLite — вопрос, прогноз, модель, стоимость по ai_guard, время, итог после резолва (для этапа 2: калибровка).
8. Тесты на фейковом клиенте Metaculus без сети: разбор типов вопросов (binary / numeric / discrete / multiple choice),
   формат отправки, «не прогнозировать дважды», ai_guard-лимит → честный пропуск, не падение. Мутации.

## Приёмка
- dry-run на 5 вопросах с рассуждениями;
- `.env` и журнал вне git (`git check-ignore`);
- стоимость одного прогноза по леджеру ai_guard (ожидание: центы);
- инструкция для Никиты: как создать бот-аккаунт, где взять токен, как положить без чата.
