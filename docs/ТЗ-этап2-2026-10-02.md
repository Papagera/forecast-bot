# ТЗ, этап 2: стать лучше шаблона

Постановщик — income, 02.10.2026, «да» Никиты. Делать после этапа 1.2 (Actions + боевая отправка).
Цель — обойти штатных шаблонных ботов Metaculus (летом 2026: ~21–28-е место из 282) по месту в MiniBench и Fall 2026.
Принцип: каждое улучшение сначала доказывается на полигоне (закрытые вопросы), в бой — только то, что выиграло.

## Порядок (по ожидаемой пользе)

### A. Полигон на закрытых вопросах — первым, без него остальное не проверить
- Выгрузка через API (личный read-токен `~/.config/income/metaculus_token`, бот-токен не трогать) закрытых вопросов:
  прошлые раунды MiniBench, Summer 2026 (33022), бот-песочница. Цель — 300+ вопросов с итогом.
- Прогон бота «как будто на дату открытия вопроса». Утечка: данные и поиск — только до даты открытия
  (AskNews — фильтр по дате, архив дорогой, 5 вызовов: для полигона только quant и LLM без поиска; бюджет
  AskNews на полигон ≤ 300 вызовов). Знания модели после даты отсечь нельзя — помечать это ограничение в отчёте.
- Метрики: log score и Brier по типам вопросов; сравнение с итоговым Community Prediction там, где он есть
  (это и есть «сильный соперник»).

### B. Количественный модуль для автоматических вопросов MiniBench — главный кандидат на преимущество
- Вопросы MiniBench генерируются из открытых рядов: FRED, Google Trends, котировки, сам Metaculus.
- Распознать вопрос → взять сам ряд → посчитать вероятность или распределение статистикой:
  эмпирическое распределение изменений на горизонте вопроса, случайное блуждание с дрейфом и волатильностью
  по истории ряда, сезонность, где она есть.
- Источники без регистрации: FRED — CSV `fred.stlouisfed.org/graph/fredgraph.csv?id=<SERIES>`; котировки — Stooq
  или аналог без ключа. Google Trends — неофициально, с лимитами; если нестабильно — фолбэк на LLM.
  Нужна регистрация или ключ — стоп, вопрос income.
- Смесь quant + LLM: вес по полигону, отдельно по каждому источнику ряда.

### C. Ансамбль моделей
- 3 модели, медиана: Gemini 3.5 Flash + ещё две по полигону (кандидаты — GPT-5.5 instant, Claude Opus 4.8 high,
  судя по летней таблице). Решение — по log score на полигоне и $ за вопрос. Бюджет боя ≤ $0.15 на вопрос.
- Отдельные «взгляд снаружи» (базовая частота похожих событий) и «взгляд изнутри» (детали вопроса и новости) —
  как у победителя Q2 2025, — только если выигрывает на полигоне.

### D. Калибровка
- По полигону и боевому журналу: если вероятности систематически слишком уверены или робки — линейная поправка
  в логитах, отдельно по типам вопросов. Никаких крайних значений: клип 2–98% (log score — уверенный промах дорог).

### E. Типы вопросов
- Multiple choice — по прошлым итогам боты здесь особенно слабы: отдельный промпт и проверка на полигоне.
- Numeric/discrete — CDF шириной по неопределённости, не «точкой с хвостами».

## Правила
- Все вызовы ИИ — через ai_guard; лимиты боя этапа 1.2 не менять без income.
- Каждый блок — отдельный PR с таблицей «было/стало на полигоне». В бой — флагом в конфиге, откат одной строкой.
- Primary-бот — один (Papagera). Эксперименты — максимум 1–2 вторичных бота «Papagera-v2» (без призов),
  только если нужна живая проверка; заводит Никита, по запросу.

## Приёмка
Отчёт по полигону: quant vs LLM vs смесь, ансамбль vs одна модель, до/после калибровки — log score по типам вопросов,
$ за вопрос. В бой идёт лучший вариант. Через 2–3 раунда MiniBench — сравнение места с шаблонными metac-ботами.
