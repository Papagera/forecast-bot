Замеры вариантов, сухие прогоны и бэктесты не должны тратить боевой платный ключ поиска (AskNews и любые
квотные API). Лабораторные прогоны идут под приложением леджера `forecast-lab`, и в нём AskNews запрещён
кодом (`ForecastBot._asknews_latest` бросает исключение, если `guarded_llm.APP != "forecast"`).

**Why:** к 05.10.2026 кошелёк AskNews опустел (APIError 402001) — локальный журнал насчитал 231 вызов со 2.10,
почти все на замеры вариантов A/B/C/D/H/S/G и dry-run. Боевой бот на открывающемся раунде MiniBench остался бы
без поиска и (до PR #10) вообще без прогнозов. Урок сформулировал income.

**How to apply:** любой новый платный источник для бота — сразу с двумя вещами: (1) запрет вне боевого
приложения леджера, (2) отдельный счётчик в журнале. Для бэктестов брать бесплатные источники с отсечкой
по дате (GDELT), никогда — живой веб-поиск (утечка будущего).
