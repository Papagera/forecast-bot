`clob.polymarket.com/prices-history` отдаёт точку каждый интервал даже без торгов; у неликвидного исхода это середина
пустого стакана (бид 0.01 / аск 0.99 → ~0.50) и её дрейф. В этапе 4 (07.10.2026) это дало 905 «арбитражных окон»
negRisk с медианой 36¢ на комплект (спорт: все три исхода матча по ~0.45–0.50 за неделю до игры); по реальным
сделкам data-api (последняя сделка ≤ 2 ч) осталось 14 окон по 9.5¢. Фильтр «цена менялась за 24 ч» почти не помог
(905 → 905): дрейф середины тоже «движение».

**Why:** арбитраж и перекосы, посчитанные по середине CLOB, выглядят как деньги, а это котировки, по которым никто не
торгует. Держат тесты и мутации `pm4: В — застывшая котировка…`, проверка по сделкам в `tools/polymarket_biases.py c`.

**How to apply:** любую «неэффективность» Polymarket подтверждать сделками `data-api.polymarket.com/trades` рядом по
времени (и по каждой ноге), а не историей цены; фильтр по объёму рынка (≥ $1k) не спасает — объём бывает на одной ноге.
