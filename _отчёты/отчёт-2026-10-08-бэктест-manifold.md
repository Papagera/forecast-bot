## Почему Manifold, а не Metaculus
API Metaculus не отдаёт исход и историю прогноза сообщества закрытых вопросов — ни токену бота, ни личному токену
Никиты (`resolution = None`, `aggregations.history` пуст у 3 из 3 проверенных; `with_cp` / `include_cp_history` на
списке и карточке — то же; HTML вопроса — 403 Cloudflare). Сайт данные показывает, API — нет (на 07.10.2026).
Manifold отдаёт исход (YES/NO) и ставки с `probAfter` — вероятность толпы на t восстанавливается точно.

## Выборка
- Решённые YES/NO бинарные рынки Manifold, закрытые 08.07–07.10.2026 (t ≥ 01.07 — после cutoff Opus 5.5),

  не больше 6 на группу (42 группы).

- Базовая частота «Да» — 0.422 по 915 рынкам того же качества, закрытым в апреле–июне.

## Как отрезано будущее (метод 3A)
- Точка t = плановое закрытие − 7 сут; рынок, решённый до t, — вон; цена толпы — последняя ставка строго до t.
- Боевой путь (как `forecast.yml` на 07.10.2026): агент Gemini 3.8 Flash, 2 поиска → Opus 5.5 high, 5 прогнозов,
  медиана. Поиск — **заголовки GDELT строго до t** (у 38 из 50 нашлись), FRED/Yahoo обрезаны датой t, `fetch_url`
  выключен (страница показала бы «сегодня»), дата в промптах заморожена на t.
- Справка агента: регулярка дат после t (кроме дат из вопроса и закрытия) + модель-проверка. Признаки утечки у
  **6 из 46 (13%)**: 5 — по модели (часть — перестраховка: «на 13.08 уже …» при t после этой даты), 1 — по дате.
  Результат приведён с ними и без них.
