## Главные находки (что изменило вывод по ходу)
1. **«Арбитраж» negRisk по середине CLOB — артефакт.** 905 окон с медианой 36¢ на комплект оказались ценами
   пустого стакана у исходов спорта (все исходы матча по ~0.45–0.50 неделю до игры). По реальным сделкам осталось
   14 окон (9.5¢). Гард: «живая» цена + проверка по сделкам, мутации красные.
2. **«Лестницы» путали дату и порог** (Kraken $11B…$17.5B к одной дате). После правки 120 → 42 окна по сделкам.
3. **Скорость (Б) — ноль.** Цена после поста двигается так же, как в случайный момент (плацебо). Плюс «до резолва»
   (+24.8%) воспроизводится плацебо (+24.4%): это перекос самих рынков про удары в этот период, а не новость.

## Г. Маркетмейкинг — ответы на три вопроса
1. **Награды** ([docs.polymarket.com/market-makers/liquidity-rewards](https://docs.polymarket.com/market-makers/liquidity-rewards), прочитано
   07.10.2026, даты на странице нет): квадратичный счёт `S = ((v − s)/v)² · b` (v — max spread рынка, s — расстояние
   от середины); при середине 0.10–0.90 одностороннее участие делится на c = 3, вне этого диапазона — только
   двустороннее; выплата раз в сутки в полночь UTC, минимум $1. Живые рынки «удар по Москве/Киеву в дату»
   (06.10): max spread 4.5–6.5¢, min size 20–50 долей, ставка до **$50/сутки** на рынок; у 13 из 105 закрытых
   рынков выборки — $25/сутки суммарно. Внутри ±4.5¢ от середины в момент замера никто не стоял.
2. **Что даёт спред.** Без наград убыток ≈ **$2.9 на рынок в сутки** при 50 долях на сторону (−$5 824 за 2 038
   рыночных суток): информированные сделки приходят перед новостью (удар → «Да» в 1). Чтобы выйти в ноль, награды
   должны давать ≥ $3/рынок/сутки — на рынках с ставкой $50 это возможно, **если** доля в наградах заметная.
   Историю ставок и стакана API не отдаёт — бэктестом это не решить. Нужен форвард-замер без денег: раз в
   несколько минут снимать стакан и настройки наград, считать нашу гипотетическую долю по формуле и марк-ауты.
3. **Капитал и работа.** Котировки ставятся и снимаются через CLOB API (`POST/DELETE /order(s)`, лимит Standard —
   40 заявок/с, отмен 80/с; [trading-rate-limits](https://docs.polymarket.com/api-reference/trading-rate-limits)).
   Минимум по наградам 20–50 долей → ≈ $15–50 на сторону на рынок; для 10 рынков с запасом на инвентарь ≈
   $500–1 000 (≈ оценка). Нужны кошелёк с USDC на Polygon и ключи API — это реальные деньги, решение Никиты.
